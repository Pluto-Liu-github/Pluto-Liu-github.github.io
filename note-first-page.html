THE NOTEBOOK

给好奇心一个落脚的地方

随笔 · 开篇文案

一个人的好奇心，有时很像散落在桌上的纸片。刚刚想明白的一个问题，偶然冒出的一个点子，一段终于运行起来的代码——它们都很小，却值得有一个地方被收好。

于是，有了这一方小小天地。

把好奇写成代码，把走过的路留成笔记。

留住过程，也留住问题

这里可以放完整的作品，也可以放尚未讲圆的思考。学习并不总是沿着直线向前，有时反复修改一小段代码，才会看清自己究竟在哪里没有理解。

记录的意义，也许就在这里：让每一次尝试都留下线索，让下一次出发不必完全从头开始。

从一页空白开始

先写下一件想明白的事，先完成一个足够小的作品。让 C++ 与 Python 成为表达想法的工具，让文字把零散的理解连接起来。

不急着把目录填满。愿这个地方随时间慢慢生长，也愿每一次回来，都能看见一点点新的自己。
