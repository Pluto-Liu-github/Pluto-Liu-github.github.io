THE NOTEBOOK

把一颗小行星，放进网页里

建站 · 第一版设计记录

这个网站的视觉从名字 Pluto 出发：一颗浅陶土色的小行星，几道细细的轨道，和一块足够安静的背景。

让颜色轻一点

背景用了接近纸张的米白，标题与按钮用低饱和度的绿色。小行星保留一点温暖的陶土色，让页面在清淡之外，也有一个可以停留的视觉中心。

让内容有自己的位置

首页给出简短的介绍，再连接项目与手记。项目页面说明作品是什么、为什么做；手记页面保留独立文章，便于分享和回看。关于页面则把个人介绍与交流入口放在一起。

第一版展示这个网站本身，后续再加入真实的 C++ 与 Python 项目。每个作品都可以沿用相同的结构：问题、实现、结果，以及还可以改进什么。

让维护简单一点

页面使用 HTML、CSS 与少量 JavaScript。插画作为本地 SVG 文件保存，手记有独立的 HTML 页面。更新一篇文字时，只需修改对应页面，并在手记目录加上入口。

一个个人网站，不必一开始就完整。能持续更新，就已经很好。
