一个安放代码、文字与好奇心的个人空间。以纸张般的留白，记录作品，也记录成长的过程。

打开网站首页 ↗

为什么做这个空间

作品需要一个清楚的入口，学习需要一个可以回看的地方。这个网站把个人展示、项目介绍与学习记录放在同一条浏览路径中。

第一版包含什么

  • 首页、项目、手记、关于我与独立文章页面
  • 手记搜索与手机端折叠菜单
  • 适配小屏幕的布局和键盘可访问的导航
  • 本地 SVG 插画与无外部字体依赖的样式

视觉上的选择

米白作为底色，鼠尾草绿用来标记入口，浅陶土色留给小行星。用留白、细线与衬线标题，保留纸页般的安静。

实现与维护

使用 HTML、CSS 和少量 JavaScript。静态文件可以部署到 GitHub Pages；文字与页面文件一一对应，方便逐篇更新。
